# Shree Engineers Corporate Website (Plain HTML/CSS/JS)

Official corporate website for **Shree Engineers** — specializing in Heavy Industrial Design Engineering and Modern Digital Enterprise Solutions.

This repository hosts the standalone, zero-build plain HTML, CSS, and JavaScript version of the Shree Engineers portal.

---

## 🚀 Quick Start

Zero installation and no build tools required!

### Option 1: Direct Browser Launch
Simply double-click `index.html` or open it directly in any modern web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server
Run with any lightweight local web server:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js
npx serve .
```

Then navigate to `http://localhost:8000` in your browser.

## 🛠️ Tech Stack & Architecture

- **Semantic HTML5**: Fully structured, accessible markup.
- **Tailwind CSS (CDN)**: Modern utility-first styling with responsive layouts and dark/light color palettes.
- **Vanilla JavaScript (`script.js`)**: Interactive tabs for engineering verticals, tech stack filtering, quotation request modal with dynamic calculation, and instant WhatsApp inquiry generation.
- **Custom CSS (`style.css`)**: Precision CAD blueprint grid patterns, animations, and custom scrollbars.
- **Lucide Icons (CDN)**: Crisp, modern SVG icons for engineering and software disciplines.
- **Google Fonts**: Plus Jakarta Sans, Inter, and JetBrains Mono.
